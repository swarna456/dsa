# Swift DSA

A collection of **Data Structures and Algorithms problems implemented in Swift**, with each solution provided in a runnable **Swift Playground** format.

The goal is to make DSA learning and interview preparation easier by allowing you to **download, run, experiment, and understand** each solution.

## 🚀 How to Use

1. Clone or download the repository.
2. Open the required `.playground` file in **Xcode** or **Swift Playgrounds**.
3. Run the code and modify the inputs to test different cases.

## 📂 Structure

Each problem is organized in its own folder:

```text
Swift-DSA/
├── Two-Sum/
│   └── Two-Sum.playground
├── Valid-Anagram/
│   └── Valid-Anagram.playground
├── ...
└── README.md
```

Each problem includes the **solution, explanation, examples, and time & space complexity**.

## 📚 Problems

* Two Sum — Array, Hash Map
* Valid Anagram — String, Hash Map
* More problems will be added regularly.
